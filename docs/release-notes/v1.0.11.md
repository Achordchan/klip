Klip 1.0.11 是重写后的第一个正式版本，也是第一个在 GitHub 发布的版本，提供 Windows 和 macOS 版。

安装：
- Windows（64 位）：下载 Klip-1.0.11-setup.exe 运行即可。
- macOS 12 及以上：Apple 芯片下载 Klip-1.0.11-mac-arm64.zip，Intel 芯片下载 Klip-1.0.11-mac-x64.zip。解压后把 Klip 拖进“应用程序”文件夹。
  - Mac 版暂未签名。第一次打开时系统会提示无法验证开发者，请点“完成”，然后到“系统设置 → 隐私与安全性”，在页面下方找到 Klip，点“仍要打开”。之后就能正常打开。
  - Mac 版暂时不能自动更新；有新版本时，Klip 会提示并给出对应的下载地址。

从旧版升级（1.0.10 及更早）：
- 旧版不会自动收到这个版本，请下载安装包直接覆盖安装。
- 历史记录、置顶与备注、图片和文件、设置、登录状态、云同步、开机启动都原样保留。
- 安装时会清掉旧版的 .NET 程序文件；程序文件名改为 Klip.exe，开始菜单和桌面快捷方式会一并更新。

这个版本有什么：
- 无感更新：以后有新版本时，Klip 会在后台下载好，等你离开电脑几分钟、Klip 的窗口都关着时自动换上并重新启动，不弹窗、不打断；装不上会自动回到原来的版本。
- 不再需要 .NET 运行时，程序更小、更省内存。
- 偏好设置改为“保存”后生效；可以把存储位置迁移到别的文件夹；图片可以存成 WebP 节省空间。
- 悬停预览框里的文字可以选中和复制。

云同步说明：
- 两台设备都改了历史时，以较新的一次为准覆盖另一边，不会合并；建议改动后等“同步成功”再去另一台设备。
- 新账号第一次同步会自动上传本地历史。
- 1.0.10 和 1.0.11 的设备可以同时用同一个账号。

不再支持 32 位 Windows。
