Klip 1.0.12 新增 macOS 版，国内网络也能顺利检查和下载更新，并修复了 Windows 上迁移存储后无法重新启动的问题。

安装：
- Windows（64 位）：下载 Klip-1.0.12-setup.exe 运行即可。已经装了 1.0.11 的，会在你离开电脑时自动更新，不用手动操作。
- macOS 12 及以上：Apple 芯片下载 Klip-1.0.12-mac-arm64.zip，Intel 芯片下载 Klip-1.0.12-mac-x64.zip。解压后把 Klip 拖进“应用程序”文件夹。
  - Mac 版暂未签名。第一次打开时系统会提示无法验证开发者，请点“完成”，然后到“系统设置 → 隐私与安全性”，在页面下方找到 Klip，点“仍要打开”。之后就能正常打开。
  - Mac 版暂时不能自动更新；有新版本时，Klip 会提示并给出对应的下载地址。

更新：
- 检查和下载更新时，会同时尝试 GitHub 直连和几条国内中转线路，自动选用最快的一条；某条线路出问题时会自动换下一条。访问 GitHub 慢或打不开的用户，从这个版本起也能正常收到更新。
- 更新信息带有签名，Klip 只接受签名正确的更新，经过中转线路下载也不会被篡改。
- 已经装了 1.0.11 的国内用户，如果连不上 GitHub，这一次需要手动下载安装 1.0.12，之后就会自动更新。

修复：
- Windows：在偏好设置里迁移存储位置后，Klip 没有重新启动。
